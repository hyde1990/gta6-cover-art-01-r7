## Vice Cover Studio — Simian Cyber World

Vice Cover Studio turns your own photo and a caption into GTA 6-style
multi-panel cover art, exported as a PNG you can post. The theme is
**Simian Cyber World**: a procedural Simian Prime character drawn entirely
by code — neon-cyan visor, chrome headset, chrome jacket, holographic
banana — set against a neon jungle skyline in green `#39ff88` and magenta.

What it does:

- **Any photo** — drop in one photo or several from your machine. Photos are
  read locally in your browser and never uploaded anywhere.
- **Crop and position each photo** — click a panel to select it, then zoom
  and pan it into place. One button fills every photo panel with a single
  photo; load more photos to fill panels individually.
- **Six layouts** — Slash diagonal (the default), Grid, Trio, Strips, Duo
  and Center. Every layout keeps the Simian Prime hero panel and gives the
  rest to your photos.
- **Caption** — two editable lines (defaults `SIMIAN CITY` /
  `Cyber Jungle Nights`) in chrome/foil lettering with a neon glow slider
  and an animated light sweep in the preview (frozen in the export).
- **Neon grade** — a WebGL2 + GLSL pass (neon grade, bloom, halftone,
  grain, vignette) over a 2D canvas render, with a plain 2D fallback when
  WebGL2 is unavailable.
- **Fast and easy** — photo in, PNG out in a few steps, in the common post
  sizes 1080x1080, 1080x1350 and 1920x1080.
- **Original work only** — no Rockstar logo, wordmark, official artwork,
  character or game font. The Simian Prime art is drawn by code, the sample
  photos are procedural art generated by the project's own scripts, and the
  lettering uses system fonts (no font file is shipped).

## Run

```sh
node serve.ts          # serves app/ at http://localhost:8080
node --test            # Node tests: layout/caption logic, dossier run, edge cases
node tools/shots-driver.mjs   # regenerates screenshots/ with Playwright
```

Open http://localhost:8080, add a photo, pick a layout, edit the caption,
and press **Export PNG**. The app is plain static files under `app/` — no
build step, no network request — so `app/index.html` also opens directly in
desktop Chrome offline.

## Layout

- `main.ts` — entrypoint: copies `app/` and `screenshots/` to the output
  directory and writes `dossier.json` with `buildDossier` from
  `vendor/makefun-app.ts`.
- `serve.ts` — tiny static server for `app/` (Node 22 standard library only).
- `app/index.html`, `app/style.css` — editor page and styling.
- `app/src/layout.js` — the six layouts, caption fitting, photo transforms
  (pure functions, covered by tests).
- `app/src/simian.js` — the procedural Simian Prime character and neon
  jungle backdrop, drawn by code.
- `app/src/cover.js` — draws the whole cover: panels, photos, Simian hero,
  neon edges, halftone/grain grade, chrome caption.
- `app/src/glgrade.js` — WebGL2 + GLSL neon grade pass (bloom, halftone,
  grain, vignette).
- `app/src/main.js` — wires the editor UI, panel selection, export.
- `app/src/shots.js` — fixed scenes for screenshots (`?shot=editor`,
  `?shot=cover`).
- `app/samples/` — procedural sample photos generated by
  `tools/make-samples.mjs`.
- `tools/shots-driver.mjs` — Playwright driver that takes the screenshots
  and verifies the real export path end to end.
- `tests/` — Node tests.
